Security architecture

How the Migration Factory protects BECU's data at every step.

🔒
Data never leaves AWS
The pipeline runs 100% inside your AWS account in us-east-1. Files go to S3, Lambdas process them in memory, outputs stay in S3. Nothing crosses to the public internet.
📄
Workflows contain code, not data
The .yxmd files are XML with logic — SQL, formulas, connections. They contain no rows, no member PII, no balances. Sharing them is like sharing source code, not a database dump.
🧠
Bedrock doesn't train on your data
AWS Bedrock guarantees that prompts and responses are never used to train models or shared with Anthropic. This is covered by AWS's BAA (Business Associate Agreement).
🛡️
AI gateway redacts before sending
The Propose Lambda sends only metadata to the model — table and column names. Never values. The parser redacts emails, SSNs and sensitive literals before anything touches the AI.
🔑
Least-privilege IAM
Lambdas have permissions only for the two specific S3 buckets and Bedrock. No access to any other AWS service or account resource.
🏦
Production runs in BECU's account
This POC runs in a Point B sandbox. In production, the entire infrastructure deploys inside BECU's AWS account, under BECU's IAM roles, VPC, and security policies.
🧪
Synthetic data only
All data in Snowflake is artificially generated — invented members, fictional balances shaped from the SQL inside the workflows. Zero real BECU member data exists in any bucket.
📋
Full AI audit trail
Every AI call is logged in CloudWatch with template name, version, model, token count, and prompt/response fingerprints. BECU retains full visibility and control.
